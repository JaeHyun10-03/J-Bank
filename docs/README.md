## 핵심 설계 판단

문서 전체에서 반복해서 근거로 쓰이는 판단들이다.

**되돌리는 비용으로 우선순위를 가른다.** 나중에 바꿀 때 이미 쌓인 데이터나 이미 붙은 클라이언트를 건드려야 하는 항목은 처음부터 지키고, 그렇지 않은 항목은 측정 후에 손댄다. 락 획득 순서·금액 타입·API 응답 계약은 앞쪽이고, 인덱스·캐시·커넥션 풀은 뒤쪽이다. 구현계획 7절.

**원장은 확정된 금전 이동만 담는다.** 2차 인증 대기 중인 금액은 원장을 건드리지 않고 계좌의 지급정지 금액으로만 관리한다. 그래서 취소된 거래가 정합성 대사를 깨뜨리지 않는다. ERD 2.2절, 요구사항명세서 FR-TXN-002.

**커밋과 메시지 발행 사이의 원자성은 발신함으로 확보한다.** 이벤트를 원본 거래와 같은 트랜잭션에서 데이터베이스에 먼저 쓰고, 별도 발행기가 폴링해 보낸다. 최소 한 번 전달을 보장하고 중복은 소비자 측 멱등 처리로 흡수한다. ERD 2.9절.

**규제 접근이 막힌 구간만 대체한다.** 실명확인, 고액현금거래 보고, 전자서명은 감독당국 승인을 받은 사업자만 접속할 수 있다. 처리 절차와 데이터 구조는 실제 규정대로 설계하고 접근 불가 구간만 목업으로 바꿨다. 요구사항명세서 7.1절, 인프라아키텍처 13절.

**모듈 경계는 검증된 뒤에 굳힌다.** 단일 모듈에서 도메인 패키지로 나누고 의존 방향을 ArchUnit으로 강제한 뒤, 경계가 실제로 지켜졌음이 확인되는 Phase 3에 한 도메인만 분리한다. 폴더구조 3절과 4절.

## 로컬 개발 환경

### 요구 도구

| 도구 | 버전 |
|---|---|
| Java | 21 (Temurin/Zulu 무관, `apps/jbank-api/gradle.properties`가 `/opt/homebrew/opt/openjdk@21`을 가리킨다) |
| Docker / Docker Compose | 최신 |
| Node.js | 20 이상 |

### 최초 세팅

```bash
scripts/bootstrap.sh
```

도구 버전 확인, 프론트엔드 의존성 설치, 로컬 인프라(core 프로파일) 기동까지 한 번에 한다.

### 로컬 실행

```bash
# 인프라: PostgreSQL 16 + Redis 7
scripts/dev.sh core

# 백엔드
cd apps/jbank-api
./gradlew bootRun --args='--spring.profiles.active=local'
# http://localhost:8080/actuator/health
# http://localhost:8080/swagger-ui.html

# 프론트엔드
cd apps/frontend
npm run dev
# http://localhost:3000
```

메시징(Kafka), 관측 스택(Prometheus/Grafana/Loki)이 필요하면 프로파일을 더한다.

```bash
scripts/dev.sh core messaging
scripts/dev.sh core observability
```

전부 동시에 띄우는 단축 명령은 두지 않는다. 성능 측정 조건이 매주 달라지는 것을 막기 위해서다(`infra/compose/docker-compose.yml` 프로파일 구성, `10_J-Bank_폴더구조.md` 7절).

인프라를 내리려면 `scripts/clean.sh`.

### 문서와의 편차

작업노트(`00_프로젝트-작업노트.md`) 작성 시점 이후 외부 생태계가 바뀐 지점 두 가지를 환경 세팅 시점에 반영했다. 근거는 `adr/0001-spring-boot-version.md`, `adr/0002-tailwind-v4.md`.

| 문서 결정 | 실제 적용 | 이유 |
|---|---|---|
| Spring Boot 3.3 | Spring Boot 3.5.16 | 3.3은 Spring Initializr에서 더 이상 제공되지 않음(OSS 지원 종료). Spring Security 6 등 문서가 전제한 3.x API는 동일하게 유지되는 3.5 라인으로 대체 |
| Tailwind CSS(버전 미지정) | Tailwind CSS v4 | `create-next-app@14`가 기본으로 깔던 v3 대신 최신 v4로 교체(shadcn/ui v4 설정 포함) |
