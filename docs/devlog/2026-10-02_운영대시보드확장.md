# 2026-10-02 운영 대시보드 확장

운영 Prometheus가 api 지표를 모으기 시작한 날(prod-metrics-scrape), 이체 패널 5개뿐이던 운영 대시보드를 `J-Bank 운영`으로 바꾸고
입금 반영·API 전체·JVM 행을 더했다. 명세: `.claude/tasks/ops-dashboard-panels/task.md`, 구성: 인프라 문서 3.5절.

## 한 일

- **쿼리 재사용**: perf 대시보드에 이미 검증한 식(입금 반영 3종, API p95, 5xx 비율, JVM 힙·GC)이 있어 job만 `jbank-api`로 옮겼다.
- **사용자 결정**: 제목만 바꾸고 uid는 유지(북마크 유지), 오류율은 5xx와 4xx를 따로.
- **서식 유지**: 기존 JSON이 한 줄 객체로 손으로 정리돼 있어, `json.dumps`로 다시 쓰면 파일 전체가 바뀐다. 일회성 스크립트로 기존 패널은
  gridPos y만 한 칸 내리고 새 행·패널을 같은 서식으로 덧붙였다.

## 겪은 문제

- **5xx 패널이 계속 빈 그래프가 될 뻔함**: 운영에는 5xx 계열 자체가 없어서 `5xx 합 / 전체 합`은 트래픽이 있어도 결과가 비어 "오류 0"과 "요청 없음"이
  구분되지 않는다. 계획 리뷰에서 지적받고 perf의 `(오류 합 or 0 * 전체 합) / 전체 합` 형태를 전체 합계로 썼다.
- **GC 단위**: perf 패널은 GC 멈춤 비율(%) 패널에 최대 멈춤(초)을 섞어 0.05초가 5%로 보였다. 운영에서는 패널을 나눴다.
- **"없는 경로 404"가 실제로는 401**: 검증 절차에 `/api/v1/no-such-path`를 404 예시로 적었는데, 공개 경로가 아니라 보안 필터에서 401(uri `UNKNOWN`)로
  끝난다. 404·`/**`는 공개 경로 패턴 안의 `/actuator/health`로 만들고, 요청 전후 `uri="/**"` 카운터가 1→4로 오른 것으로 그 요청이 `/**`로
  기록됨을 직접 확인했다. 제외 정규식은 같은 5분 창에 `UNKNOWN`·`/**` 요청이 있었는데도 p95 결과에 `GET /api/v1/products` 하나만 남는 것으로 확인했다.
- **운영에 이미 401이 68건**: 작업 전부터 인터넷 탐색 요청이 보안 필터에서 401로 막히고 있었다. 4xx 비율에는 그대로 잡힌다.
