# 2026-08-18 홈 화면 피그마 시안 재구현

사용자가 홈 화면 UI에 불만을 표하며 피그마 링크
(`Bank` 파일, node 54:22 `Home`)를 주고 그대로 구현해달라고 요청한
세션.

## 스코프 확인

`get_metadata`·`get_design_context`로 노드를 뜯어보니 실제 계좌
정보 말고도 토스 자체 위젯이 섞여 있었다 — 타행 계좌 가져오기(오픈
뱅킹), 카드 소비 요약, 내 자산(타행 계좌 집계·이번 달 지출), 알림
벨, 피드백 배너, 홈 화면 커스터마이징. 전부 J-Bank 백엔드에 없는
기능이라(카드 도메인 자체가 없음) 구현 전에 사용자에게 처리 방향을
물었다.

답은 "UI는 피그마와 완전히 동일하게, 기능은 나중에 백엔드부터
붙이는 방향으로" — 그래서 먼저 `docs/07_J-Bank_구현계획.md` 13절에
보류 결정과 근거를 기록한 뒤 코드에 착수했다(구현계획 12절 "요구사항
명세서에 없는 기능은 문서에 먼저 반영" 원칙).

## 구현

`app/page.tsx`를 피그마 구조 그대로 다시 짰다. 아이콘은 Figma가
내려준 SVG 에셋(7일 후 만료) 대신 이미 쓰고 있던 `lucide-react`로
1:1 매핑했다 — 카피 아이콘은 기존에도 썼고, 케밥 메뉴는
`MoreVertical`, 은행 아이콘은 `Landmark`, 지출 아이콘은 `Receipt`로
대체. 새 의존성 추가 없이 끝났다.

실데이터로 채운 부분과 정적으로 둔 부분을 나눴다:

- 채움: 계좌번호·잔액·출금가능액, 이체하기 링크, 2번째 이후 보유
  계좌(내 자산 카드의 "계좌" 목록으로 옮김 — 오픈뱅킹 없이도 이
  자리를 실제 데이터로 쓸 방법), 피드백 배너의 고객명 개인화.
- 정적: 가져오기 버튼(핸들러 없음), 편집 버튼, 카드 소비 위젯(0원
  고정), 이번 달 지출("? 원" — 피그마 원본에도 이미 물음표 placeholder
  였다), 푸터 링크(간편 홈 모드/홈 화면 설정), 피드백 배너 클릭.

로그아웃 버튼은 피그마 시안에 없지만 그대로 남겼다 — 이 앱에는
마이페이지/설정 화면이 없어서 홈에서 빼면 로그아웃할 방법이
없어진다. 화면 하나 없다고 계정을 못 나가게 만드는 건 우선순위가
뒤바뀐 판단이라 사용자에게 묻지 않고 유지했다.

## 검증

`eslint`·`tsc --noEmit` 통과 확인 후 Chrome으로 로그인된 상태에서
실제 홈 화면 렌더링 확인 — 계좌 2개(1번은 카드 상단, 2번은 내 자산
목록)와 실제 잔액이 정확히 반영됐고 피드백 배너 문구도 로그인한
고객 이름으로 나왔다.

확인부터 하고 진행해야 한다.
