# 2026-08-19 이체 금액 빠른선택 칩 버튼 너비 버그

스크린샷 첨부가 안 되는 이슈부터 시작해 로컬 파일 경로로 확인한
결과, 화면 전체 스타일이 깨져 있었다. 원인은 코드가 아니라
프론트엔드 dev 서버 상태 — `layout.css` 요청이 503을 반환하고
있었다. `.next` 캐시 삭제 후 dev 서버 재시작으로 해결(코드 변경
없음, 커밋 대상 아님).

## 버그

스타일이 정상화된 뒤에도 이체 금액 입력 화면의 `+1만`/`+10만`/
`+100만`/`전액` 칩 버튼 4개가 피그마 시안과 달리 왼쪽에 쪼그라
붙어 있었다.

`app/accounts/[accountId]/transfer/page.tsx`에서 칩을 감싸는
`<div className="flex gap-[8px] px-[24px] pb-[16px]">`에 `w-full`이
빠져 있었다. 부모 `MobileScreen`이 `items-start`라 flex-column의
기본 stretch가 적용되지 않으므로, `w-full` 없는 자식은 콘텐츠
너비로 shrink되고 그 안의 `flex-1` 버튼들도 같이 쪼그라든다. 같은
패턴이 계좌번호 이체(193번째 줄 부근)와 휴대폰번호 이체(264번째
줄 부근) 두 곳에 동일하게 있었다.

## 검증

Chrome으로 `/accounts/9/transfer` 실제 렌더링 확인 — 수정 전/후
스크린샷 대조, 칩 4개가 전체 폭을 균등 분할하는 것 확인.
