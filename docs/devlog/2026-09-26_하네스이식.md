## 발견한 것

### snapshot.json에서 `.env`를 빼면 회귀 테스트가 깨진다

J-Bank 루트에는 `.env.local`만 있어서 처음엔 `extra_files`를 `.env.local` 계열로만 바꿨다.
`test_explicit_ignored_input_is_snapshotted`가 `.env` 변경 감지를 가정해서 실패했다.
`.env`를 되돌리고 `apps/frontend/.env.local`만 추가했다(fixup으로 1번 커밋에 합침).
교훈: 하네스 설정 기본값은 테스트 전제일 수 있으니 바꾸기 전에 테스트부터 돌린다.

### checks.json은 셸을 거치지 않는다

`cd apps/frontend && ...`를 쓸 수 없어서 전부 루트 기준 명령으로 바꿨다.

| 검사 | 명령 | 결과 |
| --- | --- | --- |
| 하네스 | `python3 -m unittest discover -s tests` | 37 OK |
| lint | `npm --prefix apps/frontend run lint` | 통과(경고만) |
| 타입 | `apps/frontend/node_modules/.bin/tsc -p apps/frontend --noEmit` | 통과 |
| Jest | `npm --prefix apps/frontend test -- --ci` | 5 passed |
| 백엔드 | `apps/jbank-api/gradlew -p apps/jbank-api test spotlessCheck` | 성공, 2분 9초 |
| 빌드 | `npm --prefix apps/frontend run build` | 성공 |

`tsc`는 `npm exec`로 돌리면 cwd가 루트라 tsconfig를 못 찾아서 바이너리를 `-p`로 직접 호출했다.
백엔드는 Testcontainers라 Docker 데몬이 꺼져 있으면 실패한다 — CLAUDE.md에 `block` 처리 규칙을 적었다.

### Hook 동작 확인

`hook-edit`에 앱 파일 경로를 넣으면 거부, `docs/` 경로는 허용, `hook-session`은 안내 메시지 출력.
