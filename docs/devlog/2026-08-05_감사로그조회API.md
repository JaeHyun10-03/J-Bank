# 2026-08-05 감사 로그 조회 API 구현 (W4 수, 일부)

목표: `todo/W4.md` 요일별 계획의 수요일분 중 API-020(GET /admin/audit-logs) 구현.
거래내역 조회 기간·유형 필터는 아직 안 됨 — 목요일 착수분에서 이어감.

## API-020 GET /api/v1/admin/audit-logs

`eventType`/`actorId`/`from`~`to` 네 필터를 모두 선택 파라미터로 받아
`JpaSpecificationExecutor`로 동적 조합한다. 문서 갭 항목대로 운영자 역할
모델이 아직 없어 W3 API-004와 같은 방식으로 인증된 사용자면 호출 가능하게
열어두고 컨트롤러에 ponytail 주석을 남겼다. 운영자 로그인이 생기면
`hasRole('OPERATOR')`로 좁힌다.

## 검증

컨트롤러는 `@WebMvcTest`로 인증 여부(401)와 쿼리 파라미터가 서비스에 그대로
전달되는지, 서비스는 Mockito로 응답 DTO 변환을 검증했다.

## 확인

`./gradlew test` 통과. 커밋 2개(`feat`/`test`)로 분리.
