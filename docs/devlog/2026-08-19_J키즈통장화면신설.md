# 2026-08-19 J키즈 통장 상세 화면 신설 및 연결

"J키즈 적금 페이지에서 다음 버튼 누르면 이 페이지가 나와야해"라며
피그마 `ProdJKidsBank-Detail`(node-id 171-82) 링크로 요청. 실제
CTA는 "다음"이 아니라 기존 "적금 만들기" 버튼(지금까지 onClick이
없던 버튼)이었고, 이 버튼이 눌렸을 때 이동해야 하는 다음 화면이
바로 이 노드였다.

## 확인

`get_design_context`로 노드를 가져와 보니 J키즈 "적금"이 아니라
J키즈 "통장"(뱅크 계좌) 소개 화면이었다 — 지난 세션에 만든 적금
약관 아코디언 내용 중 "J키즈 통장 가입을 통해 자동으로 적금도
가입된다"는 문구와 앞뒤가 맞는 구조. CTA도 "통장 만들기"로
적금과는 다른 상품.

## 구현

- `_details/j-kids-account.tsx` 신설, `page.tsx`의
  `DETAIL_SCREENS` 맵에 `"j-kids-account"` 슬러그로 등록(기존
  `j-kids`/`j-farm`/`credit-loan`/`one-checkcard` 패턴 그대로
  재사용).
- `j-kids.tsx`의 "적금 만들기" 버튼에
  `onClick={() => router.push("/products/j-kids-account")}` 연결.
- 일러스트가 ellipse/vector SVG 15개로 구성된 캐릭터 그림이라,
  전부 피그마 에셋 서버에서 다운로드해 `public/products/
  j-kids-account/`에 커밋(URL이 7일 후 만료되므로 반드시
  로컬 파일로 저장). back 아이콘도 기존 `j-kids/back.svg`와
  동일한 아이콘이지만, 기존 프로젝트가 화면별 폴더에 에셋을
  중복 보관하는 관례를 따라 별도로 받아뒀다.
- 피그마 원본은 절대좌표 레이아웃(상태바 40px 오프셋 포함)이라,
  기존 `j-kids.tsx`가 쓰는 flex 플로우 레이아웃으로 변환하면서
  상태바 오프셋을 빼고 각 블록 사이 간격만 상대값으로 재계산했다.
  화면 하단의 빈 회색 배경 블록(`#171:83`)은 이 피그마 노드 안에
  내용이 없는 채로 들어있어서, 그대로 빈 배경 섹션으로 재현했다
  — 콘텐츠가 필요해지면 나중에 채우면 됨.

## 검증

Chrome으로 `/products/j-kids` → "적금 만들기" 클릭 →
`/products/j-kids-account`로 실제 이동, 캐릭터 일러스트·금리
정보·"통장 만들기" CTA가 피그마 스크린샷과 시각적으로 일치하는 것
확인. `npx tsc --noEmit`에 신규 파일 관련 에러 없음.
