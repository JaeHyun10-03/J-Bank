# 2026-08-26 포트폴리오 데모 고지 배너·메타데이터 추가

배경: `www.j-bank.site` 도메인 연결 전, 은행 유사 이름/UI를 쓰는
사이트가 피싱 피드 크롤러(Netcraft, APWG, Google Safe Browsing)에
자동 탐지·차단되는 걸 막기 위한 고지가 필요했다. 다운로드 폴더에
받아둔 참고 파일(`demo-disclaimer.tsx`, `layout-metadata.ts`) 내용을
검토 — 위험한 코드 없고, "포트폴리오 데모/실제 금융기관 아님" 문구를
SSR HTML과 메타데이터에 노출하는 순수 고지 컴포넌트임을 확인 후
그대로 적용했다.

## 적용 내용

- `components/demo-disclaimer.tsx`: `DemoDisclaimerBanner`(상단 sticky
  배너), `DemoDisclaimerFooter`(하단 푸터) 두 Server Component 추가.
  `'use client'` 없이 SSR 최초 응답 HTML에 그대로 포함되도록 함 —
  크롤러가 최초 응답만 읽기 때문에 dismiss 로직으로 조건부 렌더링하면
  의미가 없다.
- `app/layout.tsx`: 배너를 `<body>` 최상단(Providers 밖)에, 푸터를
  children 뒤에 배치. `metadata`를 `metadataBase: https://j-bank.site`
  포함해 교체 — description/OG/Twitter 카드 전부에 "portfolio
  demonstration project / NOT a real financial institution" 문구를
  실었다.

## 검증

`npm run build` 통과(25개 라우트 정상 생성).
