# 2026-08-19 J키즈 적금 상품 안내 아코디언 구현

이전 세션(2026-08-19 상품 화면 피그마 재구현)에서 J키즈 적금 상세
화면을 만들 때 하단 "상품 상세/금리안내/이용안내/약관 및
상품설명서" 4개 행을 정적 버튼만 놓고 내용을 채우지 않았던 부분.
사용자가 피그마 `ProdJKids-Terms`(node-id 160:82) 링크를 주며 왜
빠졌는지 묻고 토글 동작 + 내용을 요청.

## 확인

`figma-design-to-code` 스킬로 `get_design_context` 호출 —
해당 노드는 4개 아코디언 섹션이 전부 펼쳐진 상태의 "약관 화면" 전체
레이아웃이었다(제목별 리스트, 금리 테이블 3개, 예금자보호 배지,
약관 링크 목록까지). 필요한 아이콘 에셋(`icon-chevron-up.svg`,
`icon-chevron-right.svg`, `badge-dot.svg`)은 지난 세션에 이미
다운로드돼 있어서 새로 받을 게 없었다 — 그때 이미 이 화면을
염두에 두고 준비만 해두고 내용 구현은 빠뜨렸던 것으로 보인다.

## 구현

`j-kids.tsx`에 로컬 state(`Record<string, boolean>`)로 행별 open
여부를 관리하는 `AccordionSection` 래퍼를 추가하고, 4개 행 각각에
피그마 원문 텍스트를 그대로 채웠다. 반복되는 마크업은 작은 헬퍼로
추출:

- `SectionHeading`: 굵은 소제목 (`first:mt-0`으로 섹션 내 첫 제목만 위 여백 제거)
- `Li`: `·`/`–` 불릿 리스트 항목
- `InfoTable`: 금리안내의 표 3개(적용금리/중도해지금리/만기후금리)가
  전부 같은 스타일이라 헤더/행 데이터만 받는 공용 컴포넌트로 분리.
  피그마의 고정 px 컬럼 너비는 `style={{ flexGrow }}`로 비율만
  옮겨서(예: 96/96/161) Tailwind 동적 클래스 없이 처리.

아코디언 본문의 회색 배경(`#f7f8fb`)은 피그마에서 화면 끝까지
꽉 차는데, 부모가 `px-[20px]`로 감싸고 있어 그대로 두면 안쪽으로
찌그러들었다. `-mx-[20px] w-[calc(100%+40px)]`로 부모 패딩을
상쇄해 가장자리까지 배경이 번지도록 맞췄다.

각 행은 서로 독립적으로 열고 닫힌다(하나 열면 다른 게 닫히는
단일-오픈 아코디언 아님) — 피그마 스크린샷에 4개가 동시에 펼쳐진
상태가 있어서, 그 상태가 가능해야 한다고 판단.

## 검증

Chrome으로 `/products/j-kids` 접속, "상품 상세" 클릭 → 펼침 →
재클릭 → 닫힘 확인. "금리안내" 펼쳐서 3단 컬럼 표(가입기간/
기본금리/최고금리) 비율과 셀 텍스트가 피그마와 일치하는 것 확인.
`npx tsc --noEmit`에 해당 파일 신규 에러 없음.
