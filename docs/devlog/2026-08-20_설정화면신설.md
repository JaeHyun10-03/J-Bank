# 2026-08-20 설정 화면 신설

전체(`/menu`) 화면 우상단 톱니바퀴가 아무 데도 안 가던 걸, 피그마
`Bank` 파일 `Detail - Settings` 시안(node-id 133-1870) 그대로
채워 넣은 세션.

## 구현

1. `app/menu/settings/page.tsx` — 뒤로가기 + 중앙 타이틀 nav,
   로그아웃 배너, 앱 설정(알림/화면 모드 Beta)·보기 모드(간편 홈
   토글)·로그인(PC 로그인)·서비스 설정(오픈뱅킹) 4개 섹션.
2. `app/menu/page.tsx`의 톱니바퀴 아이콘을 `/menu/settings`로
   연결(`Link`로 감쌈).

로그아웃 버튼은 홈 화면(`app/page.tsx`)의 `handleLogout`과 동일한
패턴(`POST /auth/logout` → `authStore.logout()` → `/login` 이동)을
그대로 썼다 — 실제로 동작하는 유일한 버튼이라 목업으로 남기지
않았다. "간편 홈" 토글은 연결할 백엔드 설정이 없어 로컬
`useState`로만 켜고 끄는 순수 UI 스위치다. 알림/화면 모드/PC
로그인/오픈뱅킹은 이동할 상세 화면이 없어 `ponytail:` 주석과 함께
정적 행으로만 뒀다.

## 검증

`tsc --noEmit`으로 타입 에러 없는 것 확인. Chrome으로 `/menu`에서
톱니바퀴 클릭 → `/menu/settings` 진입, 간편 홈 토글 클릭 시 파란색
전환, 뒤로가기 버튼으로 `/menu` 복귀까지 실제 클릭으로 확인했다.
