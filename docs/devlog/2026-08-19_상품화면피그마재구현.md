# 2026-08-19 상품 목록·상세 화면 피그마 시안 재구현

사용자가 피그마 `Bank` 파일 링크를 연달아 7개 던져주며 그대로
구현해달라고 요청한 세션. 상품 목록 화면 1개(예적금/대출/카드 탭
3종)와 상품 상세 화면 4개(J키즈 적금, J팜 농장, 신용대출 한번에
알아보기, ONE 체크카드).

## 스코프 확인

`GET /api/v1/products` 응답 스키마(`ProductSummaryResponse`)와
시드 데이터(`SeedDataRunner`)를 먼저 봤다 — 백엔드에 실제로 있는
상품은 `SAV-6M-001`처럼 이름 없는 정기적금/예금 4종뿐, 피그마의
"J키즈 적금"·"J팜 농장"·신용대출·체크카드는 전부 백엔드에 대응하는
도메인이 없는 순수 마케팅 목업이었다(README 핵심 기능 표에도 대출·
카드는 없음). 이체 화면의 `DUMMY_CONTACTS`와 같은 처지라, 같은
방식(ponytail 주석 + 고정 텍스트)으로 처리했다.

## 구현

1. `BottomTabBar` 컴포넌트 분리 — 홈 화면에 인라인으로 박혀 있던
   하단 탭바를 상품 목록 화면에서도 그대로 써야 해서 리팩터링
   먼저 하고, 기능 커밋과 분리했다.
2. 상품 목록(`app/products/page.tsx`) — 칩 3개로 카테고리 전환,
   카테고리별로 다른 행 레이아웃(예적금은 금리 2단, 대출은 배지+
   금리구간, 카드는 그라디언트 썸네일).
3. 상품 상세 4종 — `app/products/[productCode]/_details/`에 화면별
   파일로 분리하고 `[productCode]/page.tsx`에서 슬러그로 라우팅
   (`j-kids`/`j-farm`/`credit-loan`/`one-checkcard`, 매칭 안 되면
   기존 `ScreenPlaceholder`로 폴백).

아이콘은 지금까지 관행대로 피그마 SVG 대신 `lucide-react`로
매핑했다(ChevronLeft/ChevronDown/Share2/Phone/MessageCircle/Bus/
Coffee/Tv/Play). 다만 이번엔 마케팅 일러스트(아기·농장·동전탑·
과일캐릭터·현금다발 등)까지 좌표 기반 도형 수십 개로 그려져 있어서,
그것까진 이모지로 단순화했다 — 개인 프로젝트 스코프에서 장식용
일러스트 SVG를 화면당 10~20개씩 내려받아 관리하는 비용이 값어치를
못 한다고 판단(ponytail 주석으로 남김). 실제 에셋이 필요해지면
피그마 익스포트로 교체하면 된다.

## 검증

`npm run build`(lint + tsc + 정적 생성) 통과 확인. 개발 서버로 각
라우트에 curl 쳐서 미들웨어 인증 리다이렉트(307 → `/welcome`)가
다른 화면과 동일하게 걸리는 것까지만 확인했고, 로그인 세션으로
브라우저 렌더링까지는 확인하지 못했다 — 후속 세션에서 필요하면
Chrome으로 스크린샷 대조할 것.
